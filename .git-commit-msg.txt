fix(illustration): surface planner schema hint AND give the review path more retry budget

The previous round found that knolling / ink-notes fail on a model ceiling
that sits on the scientific_review path, not the planner. Two changes:

1) The planner user content now carries an explicit `planning` block
   that re-states the schema's per-storyboard / per-scene / per-art
   character limits and tells the model to use one scene per distinct
   object. Multi-element instructions like "3 columns: A | B | C" now
   produce a 3-scene storyboard; without the hint, the model collapsed
   the whole brief into one scene and the review path then had to
   validate a too-long single scene.

2) The review path's `maxRetries` goes from 1 to 2, so the model has
   three attempts (at 8192 / 16384 / 16384) instead of two. With a
   multi-scene planner output, the review prompt itself grows; the
   extra retry slot makes room for the model to fit the verdict.

Combined, the two changes unblock knolling and ink-notes against the
live pipeline. If the ceiling still bites at 16384, the next move is
to also pass the schema's per-section character budget to the review
prompt so the review compresses its output.
