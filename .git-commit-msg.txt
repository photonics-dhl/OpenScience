feat(figure-audit): auto-extract paper figure list at extract stage

The figure-audit task previously required callers to supply a
FigurePlan by hand, or rely on the regex-based `figureSignal` score
boost to weight evidence passages. This commit puts the figure list
into the standard extraction pipeline: every successful
`extractHandler` call now produces a `figures` field on the
`ExtractionResult`, derived from the same `extractFigureReferences`
helper that backs the figure-audit task.

Effect:
- A new `figures: ExtractedFigureReference[]` field is added to every
  `ExtractionResult`, populated by `extractFigureReferences(passages)`
  with the `{ id, caption, pageNumber, role }` shape that the
  figure-audit task already accepts.
- The extraction is run once at the top of `extractHandler`; every
  return path (canonical proposal, paper-reading synthesis, blocked
  semantic stage, persisted-candidate reuse, legacy proposal bridge)
  now spreads `figures: extractedFigures` into the result.
- The figure-audit task becomes the natural follow-up: the workspace
  guide prompt can read `previousResult.figures` to assemble a
  FigureAuditInput for the user's chosen paper.

`ExtractionResult` extends `Record<string, unknown>`, so the new field
is purely additive. No schema migration needed; the field appears in
the agent-task `result` JSON for any sdf.extract task from this commit
onward.
