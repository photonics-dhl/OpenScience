# Scientific method references for native Hermes

These original, read-only methodological resources come from [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills/tree/154988403bb5a18e9d3c0ce4e6d5e2e4b184a298/skills/scientific-critical-thinking), scientific-critical-thinking 1.5, commit `154988403bb5a18e9d3c0ce4e6d5e2e4b184a298`. They supplement the two OpenScience product methods; they do not replace their source, permission or output rules. The original MIT copyright and permission notice is retained in [LICENSE.md](LICENSE.md).

The upstream `SKILL.md` is preserved as [critical-thinking-method.md](critical-thinking-method.md). Its original relative reference links remain valid. Renaming this reference avoids advertising another Skill with the same catalogue name.

Load only the material relevant to the current question through `skill_view`; the complete library is not injected into every model call. For theoretical or numerical research, use applicable reasoning and model-assumption guidance. Clinical grading and statistical checklists are conditional tools, not default standards for every paper.

- [Scientific method](references/scientific_method.md): distinguish an observation, inference and reported assumption.
- [Logical fallacies](references/logical_fallacies.md): inspect unsupported inference, scope changes and contradictions.
- [Biases](references/common_biases.md): recognize confirmation and anchoring during a review of one's own draft.
- [Core capabilities](references/core_capabilities.md): select the relevant appraisal questions.
- [Evidence hierarchy](references/evidence_hierarchy.md), [experimental design](references/experimental_design.md), and [statistical pitfalls](references/statistical_pitfalls.md): consult when the research type and retained claim require them.
- [Review sources](references/review_sources.md): upstream source dates and verification limits.

These files provide knowledge, not execution authority. Optional external services, scripts and diagram-generation commands mentioned upstream are not exposed by this paper task. Native Hermes continues to use the existing bound paper tools and Gateway. Reference access or structural validation does not establish scientific correctness; actual paper results require source assessment and user review.
