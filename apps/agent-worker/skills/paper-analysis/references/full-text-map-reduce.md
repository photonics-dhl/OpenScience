# Full-text Map/Reduce contract

- Inventory fixes artifact hash, parser version, pages, sections, figures, tables, equations and supplements before interpretation.
- Section-map units follow document structure and semantic dependencies. Six SDF fields never define reading partitions.
- Map concurrency is bounded independently from parsing, retrieval and browser review; each unit preserves SourceMap passage IDs and unresolved links.
- Global reduce reconstructs the argument across introduction, theory, method, results, captions and appendices. It distinguishes source text, visual transcription and Hermes inference.
- BGE/PaperQA-style retrieval recalls and challenges evidence after full-text coverage. Retrieval rank cannot prove completeness, and figure/table evidence remains separately indexed.
