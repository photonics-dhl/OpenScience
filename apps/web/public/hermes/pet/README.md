# Hermes layered pet assets

These three original production sprites were generated for OpenScience on
2026-08-15 using OpenAI image generation, with the project-owned Hermes concept
board as the visual reference. They do not contain third-party character art or
require a licensed animation runtime.

- `hermes-pet-idle.png`: neutral attentive portrait.
- `hermes-pet-blink.png`: matched gentle blink frame.
- `hermes-pet-working.png`: matched focused frame with energized constellation
  nodes.

All frames use a genuine transparent alpha channel and are normalized to the
same 824 × 824 canvas for cross-fade animation in the Personal Workspace.
