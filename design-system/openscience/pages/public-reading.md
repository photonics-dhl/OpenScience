# Public exploration and reading

- Job: let a visitor find, understand and continue into a real research object.
- First viewport: title/contribution, media or reading anchor, then the primary
  reading action. Source and evidence details follow the first decision.
- Use editorial measure and calm surfaces. Avoid dashboard metrics, repeated cards,
  decorative gradients and explanatory disclaimers in the opening.
- Public navigation owns explore, journals and guide. Account tools own settings,
  API and role-specific management.
