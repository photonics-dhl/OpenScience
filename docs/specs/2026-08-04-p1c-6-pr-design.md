## 需求基线

1. PR 向原 RO 提交变更（§8 概念表）
2. PR MUST 完整声明 §8.2 清单：变更 SDF 字段/文件、是否改变方法/数据/核心结论、新增贡献者及 CRediT、数据/代码许可、利益冲突、自动检查结果、是否要求发布新版本
3. 关联源 Branch/Fork 与目标 Branch
4. 声明字段提交时强制校验（缺项拒绝）
5. autoChecks 结构化占位（真实检查 P1D）
6. 打开 PR 发出 pull_request.opened 事件（§16 可重试/消费者幂等）
7. PR 默认继承 RO 可见性（§4.2）
8. 幂等键防重复提交、乐观锁防并发覆盖（§16）
9. PR 内展示变更 diff（复用 P1B §7.3 compareVersions）

## 现状约束

- PullRequest：§8.2 全字段内联（changedSdfFields/changedFiles/changesMethod/changesData/changesConclusion/newContributors/dataLicense/codeLicense/conflictOfInterest/autoChecks/requestsRelease/status）+ sourceBranchId/targetBranchId/authorId
- 无事件队列（P1D-2 Hermes 异步通道未建）；Notification 实体已建（type 含 pull_request.opened）
- compareVersions：版本 diff（§7.3 九类）；PR 分支 diff 需两分支 tip 版本
- validateLicenseInheritance：P1C-4 全兼容矩阵

## 架构决策（拟）

### 声明字段校验（Q1，§8.2 MUST）

- 创建时强制：changedSdfFields（非空数组）、changedFiles（非空数组）、changesMethod/Data/Conclusion（布尔）、newContributors（含 CRediT 角色数组）、dataLicense/codeLicense（目录内标识）、conflictOfInterest（非空字符串，可 "无"）、autoChecks（对象）、requestsRelease（布尔）
- 非法 → VALIDATION_ERROR 400；缺项 → VALIDATION_ERROR
- dataLicense/codeLicense 校验：P1C-4 assertValidLicenseId

### 分支 diff 展示（Q2，§7.3 复用）

- PR 详情含 diff：`compareVersions(from=target分支tip版本, to=source分支tip版本)`
- 两分支 tip 版本：Commit.branchId 落点 → Version by commitId
- 无版本（分支无 commit）→ diff 空

### 幂等 + 乐观锁（§16）

- 幂等键：PullRequest 无 idempotencyKey 字段——加迁移 14 列？**否**：§16 幂等「同 key 重发不重复」——PR 用 `@@unique([researchObjectId, sourceBranchId])` 语义？不行，一个分支可多次提交 PR。加 `idempotencyKey String? @unique` 列 → **迁移 14**（additive）
- 乐观锁：PR 更新（status 流转 P1C-8 merge；本期仅创建/列表/详情）不推进，无版本号

### pull_request.opened 事件（Q4）

- 本期无队列：事件落 Notification 行（type=pull_request.opened + payload{prId, researchObjectId, authorId, idempotencyKey}）
- Notification 幂等：PR 创建唯一（幂等键），通知随 PR 创建一次
- P1D-2 接队列时：消费者读 Notification 重放（§16 幂等）

### 可见性（Q5，§4.2）

- PR 零存储，读 canAccessRo（public 匿名可读）、写 requireMembership（§17）
- 源/目标分支必须属于同一 RO（跨 RO → 拒绝）

### 许可继承校验（Q3）

- 创建 PR 时：`validateLicenseInheritance(源RO有效许可, {text: ?, code: codeLicense, data: ?})`
  - PR 声明 dataLicense + codeLicense（§8.2），text 用源 RO text
  - 违反 → INHERITANCE_VIOLATION 409
