# P1B-9 移动端分步/抽屉编辑器与可访问性 Design

> Phase 1B SDF 与版本 — P1B-9  
> Design Gate 日期：2026-08-04  
> 对应 Spec: §5.4、§18.2、§18.3、§2.5.5  
> 对应 task-master: 3.9（移动端分步/抽屉编辑器 + 可访问性）

---

## 1. 目标与范围

### 1.1 目标
移动端以抽屉和分步页面呈现三栏全部功能（不删功能，§5.4/§18.2），并满足 WCAG AA 可访问性基线（§18.3）。

### 1.2 范围

**In Scope（P1B-9）**：
- 响应式三栏 → 移动端分步/抽屉（§5.4：不要求三栏同时显示）
  - 移动端：顶栏（大纲/编辑/面板切换）+ 抽屉（大纲 + 右侧面板）
  - 桌面端：三栏不变（P1B-8）
- WCAG AA 可访问性（§18.3）：
  - 键盘导航（Tab 顺序 + 焦点可见）
  - 明确焦点状态（:focus-visible）
  - 语义化 HTML（nav/main/aside + aria-label）
  - 图片 alt
  - 对比度 AA（文本/背景对比 ≥ 4.5:1）
- 性能（§18.3）：
  - 大文件列表虚拟化（版本列表）
  - 上传任务显示可恢复进度（附件上传）
- 测试：单测（响应式状态/抽屉逻辑）+ build + 对比度检查

**Out of Scope（Phase 1D+）**：
- E2E 浏览器测试（Playwright，Phase 1D 工具链）
- 深色模式
- 真实 AI 提取

## 3. 响应式布局

### 3.1 断点

```css
@media (min-width: 1024px) {
  /* 桌面：三栏（P1B-8 现状） */
}
@media (max-width: 1023.98px) {
  /* 移动/平板：抽屉 + 分步 */
}
```

### 3.2 移动端布局

```text
┌─────────────────────────────┐
│ 顶栏：☰ 大纲 | 编辑 | ☰ 面板 │  ← tab 切换
├─────────────────────────────┤
│ 中栏：Markdown 编辑（主视图） │
└─────────────────────────────┘
  左抽屉（滑出）：大纲 + 版本导航
  右抽屉（滑出）：建议 + 引用 + 审核
```

**实现**：
- `EditorLayout` 改响应式：桌面 grid 三栏，移动端单栏 + 两抽屉
- `Drawer` 组件：左/右滑出，aria-modal + 焦点陷阱 + Esc 关闭

### 3.3 抽屉焦点管理

```tsx
<Drawer open={leftOpen} onClose={...} aria-label="大纲">
  ...
</Drawer>
```

- open 时焦点移入，Esc 关闭，关闭后焦点还原触发按钮
- aria-hidden 非活动抽屉

## 4. WCAG AA

### 4.1 对比度

| 元素 | 现状 | 目标 |
|---|---|---|
| 正文文本 | #0f172a on #fff（≥16:1）✅ | 保持 |
| 次要文本 | #64748b on #fff（4.6:1）✅ | 保持 |
| 按钮文字 | #fff on #2563eb（5.2:1）✅ | 保持 |
| 删除线 diff | #dc2626 on #f8fafc（4.8:1）✅ | 保持 |

**验证**：全局 CSS 颜色已 AA；补 `:focus-visible` 焦点环（2px outline，对比 ≥3:1）。

### 4.2 键盘导航

- 所有交互元素 tab 可达
- `:focus-visible` 2px accent 轮廓
- 抽屉焦点陷阱 + Esc 关闭
- 编辑器 tab 顺序：顶栏 → 大纲（桌面）→ 编辑区 → 面板

### 4.3 语义化

- `header`（顶栏）+ `nav`（大纲）+ `main`（编辑区）+ `aside`（面板）
- 图标按钮 `aria-label`
- 附件 `<img>` alt
- 错误提示 `role="alert"`
