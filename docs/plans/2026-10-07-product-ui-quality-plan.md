# OpenScience 全站产品界面质量计划

## 目标

把 OpenScience 从“能用的页面集合”收敛为有明确叙事、稳定层级和一致互动语言的科研产品。Landing 的主视觉与正文保持现状；本计划优化其余页面以及 Landing 与全站导航、账户入口的衔接。

## 已确认的产品叙事

- 公开区域负责探索、阅读研究与期刊；不把私有创建动作散落在公共导航。
- 登录后的第一工作面是研究桌面：继续研究、创建/导入材料、查看 Hermes 任务与研究库。
- 研究编辑页围绕研究对象和当前产物组织；工具、证据、版本在上下文中出现。
- 使用指南邀请用户完成第一次研究动作；它是可读、可选择、可展开的研究手册，不是防御性说明书。
- Hermes 是全站共享的互动陪伴入口：桌面稳定 360px，窄屏为紧凑入口并可展开；Landing 不放浮动 Hermes。

## 页面系统

1. **公开阅读**：研究/期刊标题或真实贡献先出现，媒体与正文是视觉锚点，来源和证据按需展开。
2. **研究桌面**：当前可继续的研究和下一步动作先出现，任务状态和研究库随后出现；创建入口只在此处出现。
3. **工作区**：全局导航、研究对象上下文、局部模式三层分开；移动端把多栏变为可切换平面，不删除能力。
4. **账户与管理**：身份或管理任务先出现，设置、API、期刊管理按功能分组；表单反馈在动作附近可见。
5. **身份页**：登录/注册优先完成身份动作，Hermes 与品牌负责建立关系，不和表单争夺第一焦点。

## 共享视觉规则

- 延续冷白、墨色、青绿色、学术编辑字体与真实科研图；用留白、字号和规则线建立层级，减少同构卡片。
- 页面容器最大约 1280px；长文正文控制在舒适阅读宽度；页头不遮挡内容。
- 每个首屏只有一个主标题、一个主任务和一个视觉锚点。次要操作进入上下文菜单或局部工具栏。
- 控件统一 44px 最小触控尺寸、明确 hover/focus/active/disabled/loading/error/empty 状态。
- 动效只表达进入、选择、状态变化或展开；160–450ms，尊重 `prefers-reduced-motion`，不持续制造外围噪声。

## 分批实施

### 第一批：共享骨架与研究桌面

- 统一 ShellHeader 的层级、当前路由、账户工具和窄屏导航。
- 统一页头、主内容宽度、背景、选择色、焦点环和表面深度。
- 打磨研究桌面的首屏阅读顺序、继续研究、创建/导入、Hermes 任务和研究库。
- 保持 Hermes 统一尺寸、单一视觉对象和不遮挡内容的锚定规则。

### 第二批：公开探索、指南、期刊与研究阅读

- 用真实研究对象、期刊内容和媒体建立公开页面锚点。
- 保留指南的“资料→理解→表达→公开”流程，但减少文字堆叠，增强选择与展开反馈。
- 统一目录、阅读页、来源/证据和公开版本的页头与局部导航。

### 第三批：编辑、账户、开发者、期刊管理与异常状态

- 统一工作区三平面、编辑器、Hermes 处理状态、账户工具和管理控制台。
- 完成空、加载、失败、权限、保存反馈及长标题/中文布局。

## 验收

- 真实导航路径：公开首页→探索/指南/期刊，登录→研究桌面→创建/继续研究→Hermes/编辑器。
- 视口：1440、1280、1024、768、390、375；无横向溢出，主标题与主动作首屏可见。
- 互动：键盘焦点、账户菜单、导航当前态、主动作、Hermes 展开/关闭、减少动态效果。
- 状态：加载、空、失败、成功、禁用和长内容；检查控制台错误、布局跳动和图片尺寸稳定。
- 结果分开记录为候选、部署、实际观察和用户确认，不以构建通过替代视觉验收。

## 当前执行边界

本计划不修改 Landing 主视觉，不引入未经验证的新依赖，不使用通用设计系统覆盖既有产品语汇。设计系统文件只记录已批准的 OpenScience 决策与页面例外。

## 2026-10-08 构图修订

本轮采用 Product Design 截图审查，并实看 [Linear](https://linear.app/) 与 [Apple MacBook Pro](https://www.apple.com/macbook-pro/) 的当前网页。借鉴主标题与真实产品的比例、主次明确的阅读顺序和辅助信息退后；不移植品牌素材。研究内容、作者、公开版本与完整科学图保持真实。

私有页面沿既有 2026-10-03 决定，只在官网 HTTPS 或隔离测试环境验收；localhost 公开 API 反代不能作为正式账号登录入口。截图观察、构建与用户审美认可分别记录，登录限制不取消研究桌面、编辑器、账户和管理页的后续工作。

| 页面 | 构图与阅读重点 | 本轮修订 |
|---|---|---|
| 指南 | 邀请进入研究；真实论文是可阅读的成果样张 | 主标题与论文标题分级；纸面样张、完整科学图、邻近作者与图注；竖向场景索引在窄屏变为横向选择 |
| 探索 | 搜索与发现具体研究 | 移除贯穿页面的空色带；无图研究用标题／贡献分栏，有图研究完整展示；手机短说明与紧凑角色同排 |
| 期刊目录 | 期刊身份、领域与收录范围 | 期刊名与说明组成一张目录跨栏；检索保留在目录上沿；不编造封面与统计 |
| 登录／注册 | 身份表单是主任务，品牌邀请提供情境 | 邀请文案先于角色；表单与说明共享垂直节奏；统一纸面边界与输入反馈 |

已否定的尝试：把论文样张整块涂为深青色。独立截图批评指出该容器抢过了科研图；修订回纸面、细线与真实内容的对比。照片、插画本身的风格不能靠 CSS 改成另一种科学表达。上述修订仍是候选审美，整站剩余工作和用户接受状态由 canonical CURRENT 汇总。
