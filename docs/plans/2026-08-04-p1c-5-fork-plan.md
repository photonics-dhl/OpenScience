## Fork 事务流程（Q2）

1. 校验：源 RO visibility=public + sourceVersion 属源 RO + manifest 存在
2. 新 RO：workspaceId=目标 workspace，sdf core=源 manifest.coreJson 快照
3. 复制 artifact 行：源 manifest entries 逐个 → 新 workspace 建同 blobSha256 行（物理共享）
4. main branch（isDefault=true）+ initial commit（parent=null）+ version(versionNo=1, draft) + manifest entries
5. ForkRelation：{forkedRoId, sourceRoId, sourceVersionId, sourceContentHash=computeContentSha256}
6. 许可：默认复制源有效许可；显式 licenses → validateLicenseInheritance 阻断则 409
7. assignPublicId（§8.1 unique ID）
8. 审计：fork.create + research_object.create
