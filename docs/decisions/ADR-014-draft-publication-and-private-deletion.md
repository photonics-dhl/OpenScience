# ADR-014：分离内部草稿与公开版本，支持个人空间删除

状态：产品规则已由用户逐项确认（2026-09-13）；实现随 ef9e6e97 部署，显示收尾随02d67ddf部署，当前版本与实际观察见 CURRENT handoff。

## 背景

当前内部提交的 versionNo 同时用于公开版本编号，未公开论文已显示 v5。个人空间目前也没有完整的删除与恢复能力。将内部流程直接展示给用户，造成版本含义和内容所有权操作不清楚。

## 决定

公开版本只在主动发布时迭代；编辑与确认产生内部草稿历史。个人空间支持整项及内容项删除，30 天回收站和提前彻底删除；会话删除默认保留研究产物。公开版本所需内容和稳定链接继续保留。

完整的已确认规则、界面入口、代码依据、兼容建议和实施顺序统一维护在 [产品设计](../specs/2026-09-13-draft-publication-trash-design.md)，此处不另建平行规则表。

2026-09-14 特定勘误：用户确认 deep-sub-cycle 唯一首发误用内部 v10，授权更正为 v1 并补昵称署名。原科学内容/发布时间/收据和内部编辑序号保留，行政修改另记既有审计；旧误号仅临时兼容，未来真实公开序号优先，细节见上述产品设计及部署手册。

## 取舍

复用内部提交、快照、发布事务与内容寻址存储，不通过隐藏 vN 标签冒充模型修复，也不重建一套版本系统。回收站与发布状态分别表达生命周期，物理清除前处理共享引用；这些规则用于防止真实内容丢失和公开链接失效。

本决定不授权本轮清理任何既有真实论文、文件或会话。数据库字段、迁移路径和后台清理细节在实施时按实际依赖确定。
