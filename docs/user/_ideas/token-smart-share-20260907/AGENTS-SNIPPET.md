## Quality-first economical workflow
开发任务自动应用 token-smart，一次任务只加载所需分支。保留项目需求、权限及必要质量验收。
保留用户选择的主模型；不默认建议降档。主模型负责关键判断与集成。低成本子任务须边界明确且可可靠核验，能力不匹配及时重新分级升级。
已授权且值得独立委派时，显式选择实际可用模型/推理档，按任务风险用Luna/Terra/Sol，必要的高风险独立审查用high；不复制整段历史、不重复实现。
复杂规划、截图设计评审和完整有界分析可由已授权普通网页Chat承接，Codex自动发送/取回/核验；当前工具或登录缺失时如实说明，不伪称调用。
只传已授权的最小必要内容，不含凭据/无关私密资料。按真实生产者输出验消费者，再扩大开发；全部失败和返工计入成本。
不自动修改主模型、不默认开启Fast、不安装新能力或兑换额度。报告实际路由/检查/缺口，无完整同质量对照不报净节省率。
