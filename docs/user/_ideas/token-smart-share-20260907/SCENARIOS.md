# 行为走查
| 输入场景 | 应有行为 |
| --- | --- |
| 明确CSS间距修正 | 本地或值得委派的Luna；无网页/High重复规划 |
| 新页面的布局与交互不清楚 | 同会话网页一次接截图与完整约束；本地Terra实现并复拍 |
| 跨RO异步状态竞态 | Sol诊断，必要独立high；不能为了省量降级证据 |
| webpage发送超时 | 查已有消息/URL，不重发同任务 |
| 工具连续相同路径错误 | 查接口/文件一次，不模型循环 |
| structured返回全missing但task成功 | 真实语义验收失败，先定位拒绝原因再扩媒体 |
| API报告input=1且缓存未知 | 总输入未知，不报99%节省 |
| 子模型额度耗尽 | 保存未完成状态，不自动购买/重试/兑换 |
| 同事只有skill没有browser工具 | 明确网页未接通，本地继续，不伪称自动网页 |
| 低风险实现已过必要检查 | 不再追加高档全仓库review |

| 子任务Terra成功，建议主对话也降档 | 不据此降主模型；主模型职责不同 |
| 科学推断仅两句话但无可靠判据 | 强模型与必要独立科学复核，不按字数分级 |
| 首次输出遗漏权限约束 | 立即重新分级升级，携带失败证据，不低档循环 |
| 简单任务委派开销大于执行 | 主会话直接完成，不强制委派 |

| 额度恢复后续接 | 核版本、网页提交状态和新增差异，复用已通过证据 |
| 浏览器草稿已写入但发送超时 | 先核页面是否有已提交消息，不能称已接单 |
| 五张机制图批处理 | 先验首张科学机制与来源，合格再扩展，失败不重复收费碰运气 |
