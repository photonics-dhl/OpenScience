# 自动执行
信息充分就完成已授权任务，不停在路由建议。一次任务只读本入口，仅需要时读对应分支。

1. 查适用规则、当前状态和最小相关证据，明确真实验收；复用handoff及有效检查。任务成功、mock通过不等于产品走通。
2. 对已授权、可独立判断的复杂规划/设计/分析，按[网页交接](references/handoff.md)让普通Chat一次完成本阶段方案与验收设计。主会话不先重复解题，小修直接本地。
3. 保留用户选择的主模型，不默认建议降档；主模型负责需求、拆分、关键决策和集成。每阶段一个实现负责人，按[模型路由](references/routing.md)的风险与可验证性实际传入model/effort及最小完整任务包；不复制全部历史、不重复实现。高风险边界保留独立high审查。
4. 冗长检查用 `node <本skill>/scripts/run-check.mjs <exe> <args...>`，全日志落盘只返回摘要；Windows shell命令经powershell.exe -NoProfile -Command。工具/路径错误先定位，不盲重试。
5. 先用真实生产者输出验证最小纵向流程，再扩大实现/发布；保留失败和返工，不削弱来源、权限、科学条件和必要检查。科研按需读[科学验证](references/scientific-validation.md)。
6. 报告改动、实际路由、验收和未决项。要求量化才读[计量](references/metering.md)；缺失不补零，局部比例不冒充整体。上下文压力影响连续性时按项目交接或auto-compact保存检查点。

Skill不是常驻路由器，不自行切换当前主模型、不安装模型/浏览器、不绕过登录或自动兑换额度。已有网页/委派授权无需重复询问，但不覆盖无关私密资料。
