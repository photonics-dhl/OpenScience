# 实际路由
目标是同质量完成任务的总Codex成本，包含协调、失败与返工，不是最低档竞赛。

## 主模型与执行者分开选择
保留用户选定的强主模型，不把主对话降档作为默认省量建议。主模型掌握需求、拆分、跨任务约束、关键决策与最终集成；将有界执行委派出去，避免自己重做。仅在用户要求评估主模型且已有代表性任务证据时讨论降档，子任务成功不能证明主模型可替换。

以下表格用于子任务候选，不是主对话默认配置。低成本委派须同时满足边界明确、必要上下文齐全、结果可可靠核验；需求/架构判断、难验证的科学结论或跨模块未知影响直接使用足够强的模型。不能因任务描述短就判简单。小任务的协调成本超过收益时留在主会话。

| 任务 | 起始候选（仅工具支持时） | 升级条件 |
| --- | --- | --- |
| 确定性文本/样式小改、fixture、材料整理、可靠浏览器传输 | Luna/low | 合同或工具能力不足交Terra |
| 清晰接口下普通组件、脚本、功能实现 | Terra/medium | 跨模块约束、竞态或难定位失败交Sol |
| 跨模块、安全状态、复杂根因 | Sol/medium | 关键推理未决或独立审查用Sol/high |
| 架构、安全、并发、迁移、生产发布、科研正确性 | 可用high reviewer，Sol/high为候选 | 具体困难仍未解决才考虑Astra |
| 边界明确但需强能力 | Astra/low可选 | low不降低每token费率，按实际总耗与质量判断 |

这是候选起点，不保证普遍等质。不要统一派Sol，也不让Luna反复处理安全竞态。主模型保持用户设置；主会话很贵时，真正委派有界实现，自己只取证/集成，不重复写实现。Skill不能改变当前主模型。

- 每阶段一个负责人；reviewer只取需求、关键diff、生产者/消费者接口、检查及风险，不重新读全仓库。
- 工具支持时显式model/effort与fork_turns:none或必要最小上下文。角色锁定时遵守；requested与actual分列，模型自称不能证明切换。
- 复用仍有效且相关的agent；上下文过大则新建有界包。没有授权/模型控制工具就如实本地执行，不嵌套Codex伪装免费路由。
- 成功的低风险改动不再派高档重复审查；高风险独立复核不能省。
- 出现需求误解、遗漏关键约束、解释不清的测试失败或新跨模块影响，立即重新分级并按需升级，不等固定失败次数；传递已验证事实、失败证据与未决问题，避免升级后从头重做。升级看客观结果，不依赖执行者自信评分。
- 完成标准在委派前明确；实现通过自身测试不足以证明需求正确。主模型核对需求覆盖与真实流程，高风险用独立复核；不为省量删失败用例或放宽验收。
- 同一环境/路径/工具错误先本地定位，不付费循环。额度耗尽停止同路线重试，保存状态，不购买或兑换。
- 昂贵实现或高阶审查前，先由足够但较低成本的执行者做有界绑定预检：确认测试目标可导入、被 mock/patch 的生产符号真实存在、fixture 对准实际调用边界、所需环境能力可用。预检失败先修任务或测试绑定，不进入业务修改；它不替代实现后的真实测试与必要审查。
- 先按证据分类失败：工具、fixture、环境或任务包错误可由低成本执行者定点修复验证；只有业务语义、安全边界、生产影响、跨模块未知或修复范围变化才升级主模型或 high reviewer。升级不设固定次数阈值，也不借分类删除失败用例、创造生产接口或放宽 canonical/consumer/identity 合同。
- 不为日常开发重复A/B；新路线观察真实首轮通过、缺陷和返工，缺完整对照不报节省率。
- 复用项目既有任务记录，简记实际模型、首次验收、遗漏/返工和可得用量；无法维持质量的路线暂停复用。不要为此新增一套重复台账或付费基准。
- 普通网页一次承接设计取舍、截图UX、测试矩阵、有界算法/组件候选；本地负责仓库事实、运行、部署和最终验证。先给网页足够证据再等待判断，等待期间只做独立工作；取回后核关键约束与新增差异，不再重写同一份规划。
- 路由前估计交接与回读是否比本地完成更贵：短小确定性操作直接执行；有明确输入/输出且能独立验收的一整段工作才委派。网页/执行者返回结论、证据位置、未决项；完整日志不回灌主会话。
- 检查点保存任务范围、当前版本、网页URL及发送/取回状态、已通过证据与唯一下一步。额度恢复或上下文续接只核这些状态及变化，不重跑成功诊断，不重复发送；先确认实际模型/工具可用再继续。
- 生成结果先按实际内容和领域条件审查；非契约的措辞差异不触发付费重生成。保留任务ID及原始产物，发现具体语义错误后只修订该产物；不要以逐字模板代替科学、接口或视觉验收。
- 外部生成先验证最小真实产物，再批量扩展。失败必须带具体新证据才重试；校验失败反馈实际差异（如超长量），不只重复原限制；材料不足、能力不可用或同类工具错误不靠换更贵模型反复碰运气。修复后只补受影响验收，高风险边界不豁免。
- Fast不默认开启，不擅改用户配置；缓存/速度与实际费率共同影响成本。
