# 科研代码的验证边界

按实际模型与数值方法选择必要检查，不机械要求每项都运行。
明确公式、变量定义、单位、归一化、初始/边界条件、近似条件和所比较的可观测量。
有解析解或可信基准时优先对照；适用时检查网格/时间步收敛、守恒量、稳定性及极限情形。
修改物理假设、关键符号或近似时说明依据；用户尚未授权的关键科学假设变更须确认。
复用现有测试和基准数据，不为测试数量生成一批镜像实现的测试。
确认“程序能跑”与“物理/数学正确”是不同层次。数值未运行、方法未验证、数据未复现时分别标明。
若验证代价高，先运行能揭示错误的最小有意义算例，再说明仍需要的完整验证；不得将局部成功包装成全面验证。
这份清单是工作约定，不为特定科学结论提供正确性证明。

科研图像/视频跨模型交接或压缩提示时，保留决定含义的物体子类型、尺度、方向与适用条件，背景物体也不能退化成歧义泛称。实际图像出现错误装置或机制时，先核对来源→中间提示→图像在哪一步失真，再修受影响部分；不靠无差别重抽或降低科学验收省量。
已批准的源描述和全部必要限定能完整装入目标边界时，优先确定性组装，省去再次摘要的模型调用。不能装入时不以截断或“格式通过”代替语义完整；按任务重新拆分。源文保留不保证生成图正确，仍验收真实产物。
