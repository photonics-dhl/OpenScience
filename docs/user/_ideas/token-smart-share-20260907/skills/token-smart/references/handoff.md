# 连贯网页协作
已授权网页分析时，复杂阶段优先交普通Chat完整分析。分清普通Chat与Codex/Work，实际页面标签不是API模型证明；额度关系以当前账户权益为准。Codex传输、读回、实施、审查仍有成本。

## 内容
一次给本阶段完整可判断的包：目标、约束、必要代码/合同或截图、真实失败、排除项、交付物与验收。可交功能规划、完整有界组件候选、schema差异、测试矩阵、科学机制核对、页面布局交互方案。
网页看不到本地路径，提供实际内容或授权附件；不发凭据/Cookie/未授权私有资料，不交需要反复读取本地状态的调查。
主会话不先完整解题再让网页重做，不按小问题拆很多请求。形成整段可执行方案后实施，只有新证据改变关键假设才回同会话。网页区分事实/推断/未知，不自称本地测试通过。

## 发送与取回
按当前正式浏览器工具检查已登录普通Chat、实际标签和目标会话；授权充分直接发。登录/验证码由用户处理，不访问私有接口或历史会话文件。
保存同主题URL与简短状态（已发送/等待/取回/采纳/拒绝）。工具超时先查是否提交，不盲重发/重建页。
复用有效句柄/工具文档，仅读目标回答，不返回全历史。慢动作拆开输入、发送、读取，避免组合调用总时长触发重置；等待时做独立工作，不高频全页轮询。草稿、提交成功、回答完成分别以页面事实确认，不将点击成功或工具超时当作提交结果。
执行者同生命周期完成发送到取回；代理失效接管已有URL。主会话不重复传输。
有状态工具先确认能否交接；已由当前执行者独占的会话保持原负责人，不为降档切换控制权。将独立取证、测试等任务交给合适的低成本执行者。
已证实的工具/环境故障保留简短失败依据和可用替代路径；没有改变可用性的新证据，不重复失败操作或重读全部文档。必要的安全检查和最终验收仍须完成。
用正式页面可见文本/下载能力保存原文到授权本地位置。save-browser-text.mjs是可选旧兼容工具，不是必需路径；默认不读session JSONL，不绕过私有日志限制。不能完整传文件/读回就如实说明，不能手抄却自称逐字。
浏览器不可用先推进本地独立工作；必需登录/能力缺口才说明，不把用户手工复制粘贴作为默认过程。

## 采纳与纵向验证
只核验影响实现的接口、科学条件和风险，不在主会话重复长规划。将方案交一个负责人。
普通代码审查可一次交网页完整相关diff、需求、直接接口和真实检查结果；本地核对具体发现及需求覆盖，不再另派高档重做同一普通审查。涉及安全、并发、迁移、生产发布或其他高风险时，独立high只聚焦受影响风险与证据，不把网页GO当作发布授权或测试证明。新增diff或新失败才补交受影响部分，不重复提交未变材料。
先拿真实生产者输出经过API→消费者→关键UI，再扩大工作。结构化重试变全missing时定位具体校验失败，不能用mock数量宣称成功。网页代码只是候选，必要检查与高风险独立复核保留。

## 截图设计评审
一次发关键页桌面/移动截图、用户目标、空/加载/错误/成功状态和既有设计约束。要求优先级、具体位置、字体间距色彩、交互路径及验收。
只有实际附图才称截图评审。取回后结合项目已有design skill/组件体系实施，同视口复拍，验溢出/阅读层级/键盘/状态/真实流程。美观不替代功能正确。
