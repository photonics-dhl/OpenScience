# 为什么把研究发布到 OpenScience

## 让一次研究，成为别人可以继续使用的知识

面向学者的价值说明与传播文案｜2026 年 9 月 15 日

网站：[OpenScience](https://openscience.428312321.xyz/)

> OpenScience 将论文、数据、代码与讨论组织成开放、可验证、可演化的研究对象。发布的意义，是让同行更容易理解你的工作、核对你的证据、准确引用你的贡献，并在你的研究基础上继续探索。

### 本文的依据与使用方式

本文依据官网首页、开发者文档和一个公开研究对象撰写。文中区分“公开页面已展示”“文档已说明”和“建议建设”，避免将规划写成已经全面上线的服务。公开样本不代表所有研究对象都具备相同内容，也不构成对整个系统的功能验收。

这里的“发布”指创建或补充科研对象、发布获准公开的研究材料，以及为已发表论文建立关联入口。平台记录与期刊正式发表、同行评议分别标识。当前可核验的示例使用 OSR 标识；不能据此宣称每项研究已取得 DOI。

## 一、OpenScience 的利他特质

“利他”应当落实为读者可以获得的帮助：降低理解成本、保留证据、尊重贡献、方便复用，并让后来者少走弯路。

| 特质 | 为别人提供什么帮助 | 作者获得什么回报 | 当前依据与边界 |
|---|---|---|---|
| 1. 公开研究入口 | 读者可以直接浏览公开研究对象 | 研究有可分享的阅读地址 | 首页与公开样本可访问；公开范围由具体记录决定 |
| 2. 六字段说明 | 依次回答问题、洞察、方法、结果、局限、可复现性 | 减少反复解释背景的时间 | 公开样本与 API 文档均展示六字段 |
| 3. 结论连接证据 | 读者能够沿主张回到来源及定位信息 | 贡献更容易被核验和准确转述 | 样本展示主张与证据关系；科学正确性仍需专业判断 |
| 4. 主动写明局限 | 让同行知道结论在什么条件下成立 | 减少过度解读和错误应用 | 样本明确列出假设与未覆盖边界 |
| 5. 交代复现路径 | 帮助别人判断复核需要哪些步骤与材料 | 为方法传播和后续合作提供基础 | 有可复现性栏目；有栏目不等于结果已被独立复现 |
| 6. 保留固定版本 | 后续修订时，读者仍能指明当时使用的版本 | 便于说明成果演进和引用对象 | 样本展示版本地址、时间、版本哈希与历史 |
| 7. 提供持续对象入口 | 读者可以继续追踪研究更新 | 已发布研究具有持续维护的载体 | 文档区分最新公开版本与指定版本 |
| 8. 明确署名与引用 | 帮助使用者正确归属贡献 | 作者身份与研究对象保持关联 | 样本有作者、通讯作者和复制引用入口 |
| 9. 区分材料许可 | 读者知道文字、数据、代码分别如何使用 | 减少重复咨询，明确使用条件 | 样本分别显示文字、数据和代码许可；应逐项核对 |
| 10. 关联论文与附件 | 同行可从研究说明继续查找原文和材料 | 分散成果形成统一入口 | 文档支持附件路径；仅获准匿名下载的附件提供下载链接 |
| 11. 向研究工具开放读取 | 工具能按统一格式读取公开内容 | 研究有机会进入更多检索与分析工作流 | 文档说明公开 HTTP/JSON API 无需登录和 API key |
| 12. 让图解承担解释功能 | 非本领域读者更容易建立直观认识 | 扩大跨学科交流机会 | 样本有概念图，并明确它不作为科学证据 |
| 13. 诚实呈现缺失内容 | 读者能看出数据、代码或视频尚未提供 | 建立清楚、可信的研究记录 | 样本明确说明尚无公开视频、未核实独立代码入口 |
| 14. 为后续研究保留上下文 | 研究问题、方法、条件与版本可以一起传递 | 研究更容易被继续讨论和使用 | 已有对象结构；跨对象知识图谱仍属建议扩展 |

以上功能依据：[官网](https://openscience.428312321.xyz/)、[开发者 API 文档](https://openscience.428312321.xyz/developers)、[公开样本 OSR-2026-000023 v1](https://openscience.428312321.xyz/research/OSR-2026-000023/v/1)。本表归纳的是功能的预期价值，尚未测量其对引用率或合作数量的实际影响。

## 二、为什么作者值得投入时间发布

### 1. 让同行更快判断“这篇研究与我有什么关系”

一篇论文通常包含丰富背景、推导和结果。OpenScience 的六字段结构可以先回答读者最关心的几个问题：你解决什么问题、采用什么方法、得到了什么、适用到哪里。读者能更快决定是否进一步阅读原文。

### 2. 让贡献被准确理解

完整传播应同时包含结论和条件。把“观察到的结果”“理论预测”“推测的应用”分别写清楚，再连接对应证据，有助于减少二次传播中的夸大或混淆。作者也有一个可以持续维护的解释入口。

### 3. 让研究成果的不同部分得到使用

论文之外，数据、代码、实验流程和分析方法也可能对别人有用。将这些材料与研究对象关联，可以帮助使用者找到真正需要的资源，并识别相应作者、版本和许可。是否另行注册 DOI，应依据资源类型、合作仓储和注册政策确定。[DataCite 资源关系说明](https://support.datacite.org/docs/connecting-to-works)

### 4. 让后续更新有出处

研究可能增加数据、改进方法或补充解释。持续对象帮助别人找到当前公开版本；固定版本帮助别人记录自己实际使用了哪一版。两者结合，既支持演进，也保留可追溯性。平台文档同时说明，固定地址仍受撤回状态和访问权限约束。[OpenScience 版本说明](https://openscience.428312321.xyz/developers#versions)

### 5. 为 AI 辅助科研提供更清楚的材料

公开结构化内容能为具备相应访问与接入能力的 AI 工具提供问题、方法、主张、证据和许可。它降低了接口使用者重新抽取这些字段的成本。能被读取、进入检索结果、被正确引用，是三个需要分别验证的环节。[OpenScience API](https://openscience.428312321.xyz/developers)

### 6. 把分享变成可以积累的公共贡献

分享清楚的材料、失败边界与复现条件，可以减少同行重复整理和试错的成本。这与 FAIR 所强调的可发现、可访问、可互操作和可复用方向一致；是否达到具体要求，应按资源逐项检查。[FAIR 原则](https://www.gofair.foundation/fair-principles)

## 三、四类受益者

| 受益者 | 核心价值 | 最应保留的信息 |
|---|---|---|
| 作者 | 清楚表达贡献，集中成果入口，维护版本与署名 | 作者、原始论文、版本、贡献与许可 |
| 读者 | 更快理解、核验、比较，并判断能否复用 | 方法、证据、适用条件、局限与材料 |
| AI 与开发者 | 获得一致的结构化输入和固定版本地址 | 字段定义、来源定位、状态与稳定接口 |
| 科研生态 | 减少信息散失、重复整理和脱离证据的传播 | 开放元数据、跨资源关联与更新记录 |

## 四、建议继续建设的利他能力

这些是后续产品建议，尚未由本次公开浏览确认全面上线。

| 建议能力 | 对学者与社区的价值 | 上线前应明确 |
|---|---|---|
| 作者认领与贡献角色 | 让数据整理、软件与复现工作得到清楚归属 | 身份核验、共同作者处理、争议处理 |
| 中英文分层说明 | 服务跨语言与跨学科读者 | 专业术语与翻译审核机制 |
| 标准化 Figure Cards | 将图的目的、输入、结果与边界一起解释 | 原图编号、面板、单位及证据类型 |
| 数据期刊协作 | 让规范化对象进入同行评议和数据论文流程 | 合作协议、版本绑定与评议状态 |
| 完整导出与仓储协作 | 降低平台迁移和长期保存成本 | 导出格式、保存责任与服务终止安排 |
| Topic Hub 与关系图谱 | 帮助新人进入领域、发现相邻方法 | 纳入标准、关系证据和更新时间 |
| 可复用性反馈 | 作者了解材料是否可用、读者反馈缺失条件 | 指标口径、反馈审核与个人信息处理 |

现有项目合作材料提出“Research Object—数据论文预检—投稿包—同行评议—特定数据版本认证—持续演化—AI 发现与复用”的闭环。本表将其作为建设方向，未将合作设想写成已完成的外部合作。

## 五、可以直接用于网站的作者邀请文案

### 让你的研究，被理解，也被继续使用

你的研究值得拥有一个清楚、可追溯、能够持续更新的入口。

在 OpenScience，你可以把论文与相关材料组织为研究对象，说明研究问题、核心洞察、方法、结果、局限和复现条件。读者可以先理解研究要点，再沿主张与证据关系深入核查；研究工具可以通过公开接口读取结构化内容。

每一个清楚的研究说明，都在帮助后来者节省时间。每一条准确的证据链接，都让贡献更容易被正确归属。每一次有记录的更新，都能为后续研究留下更完整的上下文。

**把研究整理好、把证据连接好、把边界说明白，让更多人有条件在你的工作基础上继续前进。**

## 六、作者常见问题

**已经在期刊发表，还适合发布吗？**

适合为获准公开的材料、原创解读和相关资源建立关联入口。保留原文 DOI、作者与出版信息，按原文及附件许可确定可发布范围。研究对象应标明它与正式论文的关系。

**上传后就等于经过同行评议吗？**

平台发布、编辑核验、作者确认和期刊同行评议应分别标识。本次浏览没有证据支持“所有平台内容都已经同行评议”。

**每个对象都有 DOI 吗？**

本次样本显示 OSR 对象与版本标识。DOI 属于独立的持久标识注册体系；需要在实际注册后才能宣传已获得 DOI。

**一定会增加引用吗？**

不能保证。平台可以改善表达、证据组织和接口访问，但具体检索平台是否收录、AI 是否引用以及学者是否最终在论文中引用，都受多种因素影响。

**免费吗？内容会被用于 AI 训练吗？**

本次公开 API 文档说明读取公开接口不需要 API key。上传、存储、编辑服务的收费，以及训练使用的具体条款，不能由此推断，应以平台公布的政策和对应材料许可为准。
